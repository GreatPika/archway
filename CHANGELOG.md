# Changelog

## 0.2.0

- Add thin npm and pub launchers with verified native downloads and offline reuse.
- Generate ARCHITECTURE.md as the architecture guide.
- Use Dart for maintainer tooling and regression tests.

## 0.1.0

- Define flat architecture policies for TypeScript and Dart projects.
- Validate policies, inspect dependency relationships, and report architecture violations.
- Generate starter configuration and agent guidance, and export the declared module graph as Mermaid.
- Provide native command-line payloads and prepared npm and Dart package layouts.

Package staging and local installation tests do not establish registry availability.
